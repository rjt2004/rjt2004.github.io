    CS336-1 Transformer模型
    Ton3rr
      2026-08-01   2026-11-17  8.3k Words  35 Mins  

      CS336的学习笔记，参考了b站这就是小C_，intangible101的视频和笔记。

      文本编码与 Tokenizer解决了”文本 → 整数 token ID”这一步，把句子切成离散编号；Transformer 则在这些编号上理解上下文、预测下一个 token。

    Transformer整体架构预览

      语言模型接收一批句子（每个句子是一个 token ID 序列），输出每个位置上”下一个词”的概率分数（logits）：

    • 输入形状：(batch_size, sequence_length)，整数 token ID；
    • 输出形状：(batch_size, sequence_length, vocab_size)，即每个位置对词表中每个 token 的 next-token logits。

      训练时用交叉熵损失衡量每个位置的预测分布与真实 next token 的差距；推理时没有”未来”的标签，就从最后一个位置的分布中采样出下一个 token，拼回序列后再重复这一过程，逐个生成后面的 token——这就是自回归（autoregressive）生成。

      原始 Transformer 采用编码器-解码器（encoder-decoder）结构：编码器读完整输入，解码器再生成输出。现代大语言模型（GPT、LLaMA 等）统一采用 decoder-only 结构，只保留解码器，并用因果掩码保证每个位置只能看到自己和左边的 token。CS336 版 Transformer 同样是 decoder-only，每个 Transformer 块由两个子层组成，且都采用 Pre-Norm（先归一化、再过子层、最后残差相加）。

      把上图拆成伪代码，整个前向过程其实很直观：嵌入 → 若干次（注意力 + 前馈）→ 归一化 → 输出投影。

    线性层

      线性层是 Transformer 里最基础的组件：它不改变数据的组织方式，只把最后一维从 d_in 映射到 d_out。对输入 做 ，其中权重矩阵 的形状是 (d_out, d_in)。

    • 输入形状：(batch_size, sequence_length, d_in)；
    • 输出形状：(batch_size, sequence_length, d_out)。
      

      初始化使用截断正态分布，均值 0、标准差 sqrt(2 / (d_in + d_out))（Xavier/Glorot 的常用形式），并截断到 [-3σ, 3σ]。这样做的目的是让每一层输出的方差大致保持不变，避免深层网络中激活值逐层爆炸或衰减；截断则防止极少数离群权重在训练初期造成不稳定。线性层不带 bias：在 Transformer 中 bias 对效果影响很小，省掉可以让参数更少、结构更统一。

      einsum 里的 ... 会自动广播到任意前置维度，所以同一个 Linear 既能处理 (d_in,) 的单向量，也能处理 (B, S, d_in) 的整批序列，不需要为不同输入形状写分支。

    嵌入层

      token ID 本身没有语义，只是词表里的编号。嵌入层就是一张大小为 (vocab_size, d_model) 的查找表：用 token ID 去索引第 0 维，取出对应的 d_model 维向量。

    • 输入形状：(batch_size, sequence_length)；
    • 输出形状：(batch_size, sequence_length, d_model)。
        self.embed[token_ids] 是高级索引，结果形状为 token_ids.shape + (d_model,)，所以 (B, S) 的 ID 序列会得到 (B, S, d_model)。嵌入层只按 token ID 查表，同一个 token 无论出现在第几个位置，拿到的都是同一行向量——它完全不知道位置。而注意力打分只看内容，如果不额外注入位置信息，模型就无法区分同一个 token 出现在不同位置，也感知不到相对距离，这正是后面用 RoPE 的原因。

    Transformer块

      Transformer 块里有两个子层：

    1. 因果多头自注意力：让每个 token 汇总上下文信息；
    2. 逐位置前馈网络：对每个 token 独立地做一次非线性变换，整合注意力收集到的信息。

      每个子层都套在”归一化 → 子层 → 残差相加”的模板里。CS336 采用 Pre-Norm：先归一化再进子层，残差路径上不做任何归一化。这样梯度可以沿着残差路径从后一层”无损”地传回前一层，深层模型训练更稳定，也是 LLaMA、GPT-3 等现代模型的标准选择。与之相对的 Post-Norm 是”子层 → 残差相加 → 归一化”，原始 Transformer 用的就是它，但层数一深就容易训练困难。


    （Pre-Norm 为默认结构，Post-Norm 为消融选项。）

    均方根归一化

      LayerNorm 会同时做”减均值”和”除标准差”两件事；RMSNorm 观察到，在 Transformer 里减均值对效果的贡献很小，于是只保留”除以均方根”这一步，计算更省、效果接近。

      其中 g 是可学习的增益参数（共 d_model 个），初始化为全 1；eps 通常取 1e-5，防止分母为 0。归一化只作用在最后一维（特征维）上，前面的 batch、seq 维各自独立处理。

      看一个直观的例子：某一行向量是 [2, 2, -2, -2]，平方和为 16，均方根为 ，归一化后得到 [1, 1, -1, -1]，再逐元素乘上 。数值较大的行（例如 [10, 20, 20, 10]）会被压到 1 附近，从而防止深层网络前向传播时数值失控。

      数值稳定性方面，训练时权重常以 float16/bfloat16 存储以节省显存、提高吞吐，但低精度下平方求和容易溢出或丢精度。因此实现里先把 x 转成 float32 计算，算完再转回原 dtype——这一步对混合精度训练很关键。

    旋转位置编码

      自注意力本身是位置无关的：把 token 顺序打乱，注意力分数只依赖内容，不依赖谁在前谁在后。但语言是有顺序的（”狗咬人”和”人咬狗”完全不同），所以必须把位置信息注入模型。

      RoPE（Rotary Position Embedding）的思路很巧妙：不额外加位置向量，而是根据 token 的位置，把 q、k 向量”旋转”一个角度。位置 的旋转矩阵 是一个分块对角矩阵，每块是一个 2×2 的旋转子矩阵：

      其中 是 token 位置， 是维度对的编号（）， 是常数基底（GPT-2 取 10000）。不同维度对用不同频率旋转：靠前的维度转得快（高频），靠后的维度转得慢（低频），一组不同尺度的”时钟”组合起来就能唯一编码位置。

      为什么旋转能表达相对位置？两个向量分别旋转 θ_i 和 θ_j 后再做内积，结果只依赖角度差 θ_i - θ_j，也就是只依赖相对位置 i - j。这就是 RoPE 的核心性质：注意力分数天然携带”相对距离”的信息，而且不需要额外的位置向量参数。

      实现上不必真的构造 d × d 的大矩阵：把最后一维两两分组，每组独立做一次二维旋转即可。sin/cos 只和位置、维度有关，与具体输入无关，所以可以在初始化时预计算成查找表，并注册为 buffer：它会随模型一起搬运设备、保存进 state_dict，但不参与梯度更新。查找表的形状是 (max_seq_len, d_k/2)，第 i 行就是位置 i 在每一组维度上的 cos/sin 值。

      对照代码看，有几个细节值得留意：

    1. RoPE 只作用于 q 和 k，不作用于 v。旋转是为了让 q · k 携带相对位置信息；v 只负责”取什么内容”，不需要位置。
    2. 两两分组是交错的：用 rearrange 把 d_k 拆成 (d_k/2, 2)，再用 unbind 得到偶数位和奇数位两组，旋转后再用 stack + rearrange 合并回原顺序。
    3. 不能用 concat 拼回去：concat 会把所有偶数位放前面、奇数位放后面，顺序变成 (x0, x2, x1, x3)；必须用 stack 重新交错，才能保持与原向量一致的维度顺序。
    4. token_positions 是绝对位置下标，默认由调用方传入 0 ~ seq_len-1，也支持非连续位置。

    多头注意力机制

      注意力机制要解决的问题是：序列里每个 token 应该”看哪些位置、各看多重”。多头自注意力（Multi-Head Self-Attention, MHA）把这件事拆成三个子模块来学：softmax 负责把分数变成概率，缩放点积注意力负责单个头的加权求和，因果多头注意力负责把多个头拼起来并加上因果掩码。下面一个一个实现。

      先看整体流程：输入 经过一次大矩阵乘法得到 Q、K、V，然后拆成 num_heads 个头并行计算注意力，每个头各自得到一份输出，最后拼接并通过输出投影 融合。

      图中左侧是单头注意力的完整张量流程，右侧是实现要点与形状追踪。整个过程可以记成四步：

    1. QKV 投影与多头拆分；
    2. 打分、缩放、掩码、softmax；
    3. 用注意力权重对 V 加权；
    4. 多头拼接 + 输出投影。

      图里的例子是 seq_len = 4、d_model = 4、num_heads = 2，所以每个头的维度 ，图中每个头的 q、k、v 都是 (4, 2)：行是 4 个 token，列是这个头的 2 维特征。如果把两个头合起来看，拆分之前的 q、k、v 则是 (4, 4)。

      Q、K、V 是同一份输入 经过三个不同权重矩阵投影得到的，分工不同：

    • （query）：当前位置”想找什么信息”；
    • （key）：每个位置”以什么特征被检索”；
    • （value）：每个位置”实际提供的内容”。

      三者串起来就是一次注意力计算：先用 算出两两匹配分数，除以 缩放、加上掩码，再 softmax 得到每行和为 1 的权重 ，最后用 对 加权求和。

      在这个例子里， 是 (4, 2) @ (2, 4) -> (4, 4)，第 行第 列就是 token 与 token 的相关性； 同样是 (4, 4)，每行表示”token 把多少注意力分给各个位置”； 是 (4, 4) @ (4, 2) -> (4, 2)，输出第 行就是 token 聚合到的内容。

    softmax

      softmax 把任意实数向量映射成概率分布：每个值都是正数，且总和为 1。MHA 用它把原始注意力分数变成”每个位置应该分到多少注意力”。

      直接按定义计算会有溢出风险：当某个 很大时， 可能超出浮点数范围变成 inf，分母也随之变成 inf，最后得到 nan。由于 softmax 对输入整体平移不变，实现时先减去该维度的最大值：

      减完之后最大的指数项是 ，其余项都不超过 1，数值就稳定了。这就是代码里 x -= x.max(...) 那一行的作用——它不改变数学结果，只改变计算的数值稳定性。

      两处 keepdim=True 的作用是一样的：保留被归约的那一维，让它变成大小为 1，这样广播才对得上。

      两种写法都不会报错，但第二种把”每一行的最大值”减成了”每一列的最大值”。继续 exp、再除以行和（这一步仍用 keepdim=True），得到的”softmax”是 [[0.5, 0.5], [0.9820, 0.0180]]，正确答案是 [[0.2689, 0.7311], [0.9526, 0.0474]]——每行仍然和为 1，数值却已经错了。

      原因就是省掉 keepdim=True 后，被归约的维度会被删掉，形状从 (..., 1) 变成 (...)；PyTorch 的广播从最后一维往前对齐，这个 (...) 会被当成”贴在最后”的维度。加上 keepdim=True 后，就不用关心输入有多少维、i 具体是哪一维。

      另外，x.max(dim=i) 返回的是 (最大值, 最大值下标) 这个命名元组，所以代码用 [0] 取最大值；也可以写成 .values 或直接用 x.amax(dim=i, keepdim=True)。

    多头自注意力

      单个注意力头只能从一种”视角”看序列；多个头可以让模型同时关注不同的关系——有的头关注语法结构，有的头关注指代，有的头关注局部搭配。多头注意力的做法是：把 维拆成 个头，每个头维度 ，各自独立做一次缩放点积注意力，最后拼接并投影回 。

      这里 的每一行是一个 token，所以 就是把 投影成 ，得到第 个头的查询；、 同理。拼接后是 ，再乘 把各头的信息混合回原维度。按头写出的 只是数学上的拆解，代码把所有头沿输出维拼成一个 (d_model, 3 * d_model) 的 ，算完再切分——所以 Linear 里存的是 (3 * d_model, d_model)，正是它的转置。

      实现时有三个设计要点：

    1. QKV 投影合并成一个大矩阵：Linear(d_model, 3 * d_model) 一次算出 Q、K、V，比分别做三次矩阵乘法更省显存访问；
    2. RoPE 只加在 Q、K 上：位置信息通过 进入注意力分数，V 不需要旋转；
    3. 因果掩码用下三角矩阵：torch.tril(torch.ones(...)) 生成，保证每个位置只能看到自己和左边。

    逐位置编码

      FFN 是 Transformer 块里的第二个子层。注意力负责让 token 之间交换信息，FFN 则对每个位置独立地做同一次非线性变换。它的作用是把上下文真正”加工”成新特征：注意力的输出只是各位置 的加权平均（权重非负、和为 1），本质上还是在搬运已有信息，非线性组合发生在 FFN 里，它也因此占了块里约三分之二的参数。
